Questions

Straight answers.

Is it really free?

Yes on this instance. Building, AI writing, PDF and Word export are all unlocked. It's a self-hosted build running on a free model, so there's no paywall hiding behind the last step.

Where does my data go?

Your draft lives in your browser's local storage. Only the text you send to the AI features goes to the model, and nothing is stored server-side.

Will this pass an ATS?

Every template is a single-column layout with real text, standard section names, and no text-in-images. That's what parsers need. The review tool flags keyword and structure gaps on top of that.

Can I edit the Word file later?

Yes. The DOCX export builds real paragraphs with real list bullets, not a picture of a resume.

Can I move my draft between devices?

Use Export JSON in the builder, then Import JSON on the other machine.
